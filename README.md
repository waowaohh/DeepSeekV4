# DeepSeekV4 Website

这是一个介绍 DeepSeek V4 长上下文能力的静态网页项目，内容围绕百万 Token 上下文、模型架构、效率优化、评测表现与开源生态展开。

## 在线访问

- GitHub Pages: https://waowaohh.github.io/DeepSeekV4/
- GitHub 仓库: https://github.com/waowaohh/DeepSeekV4

## 项目内容

- `index.html`: 网站首页，适合直接通过 GitHub Pages 访问。
- `deepseek-v4-article.html`: 完整文章页面。
- `images/`: 页面使用的技术插图、图表和趣味插图。
- `tutorial_screenshots/`: 教程说明中使用的截图。
- `deepseek-v4-tutorial.md`: 制作过程与教程说明。
- `DeepSeek_V4_公众号推文.docx`: 公众号推文版本文档。

## 使用方式

直接打开 `index.html` 即可在浏览器中预览网页。  
如果通过 GitHub Pages 发布，访问仓库对应的 Pages 地址即可。

## 说明

本项目是一个纯静态网页，不依赖后端服务，也不需要安装额外依赖。
